# 可配置项

仅在教师没有提供更具体规则时使用这些默认值。长期偏好写入 `teacher-preferences.md`，课程类型判断写入 `rubrics/`，措辞写入 `comment-style.md`。

## 默认总评结构

- 论文权重：50%
- 小组展示权重：30%
- 出勤权重：20%

总评有两种常见数据形态：

1. `weighted_average`：三项都是百分制原始成绩。
   `总评 = 出勤 × 0.20 + 展示 × 0.30 + 论文 × 0.50`
2. `weighted_components`：出勤已经按20分制记录、展示已经按30分制记录。
   `总评 = 出勤分项 + 展示分项 + 论文 × 0.50`

必须查看表头、满分或已有公式后再选择，不能默认二者等价。

## 默认评语要求

- 长度：约180至300个中文字符，可随封面空间和教师要求调整。
- 内容亮点：至少1句，优先1至2句。
- 改进建议：至少1项，并与实际扣分对应。
- 高分、中等和低分使用不同强度的评价词。

## 可选分布约束

以下项目默认关闭，只在教师明确要求时启用：

- 分数区间
- 正态或近似正态分布
- 高分和低分人数限制
- 同分人数上限
- 必须形成无并列排序

## 规则修改位置

- 长期判断习惯：`teacher-preferences.md`
- 通用扣分逻辑：`scoring-rules.md`
- 某类论文尺度：`rubrics/*.md`
- 评语开头、结尾、禁用词：`comment-style.md`
- Excel和Word交付格式：`output-specifications.md`
