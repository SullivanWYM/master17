# 评语话术

## 基本风格

- 正式、克制、客观
- 不要只写“很好”“一般”
- 要写出论文里真实出现的亮点
- 不要把案例分析写成实证论文，也不要把论文写成空泛套话

## 通用结构

1. 选题评价
2. 内容概括
3. 具体亮点
4. 理论、材料、结构或表达方面的评价
5. 不足与改进建议
6. 总体判断

## 通用开头

- 该论文选题基本符合本课程考核内容的相关要求。
- 该论文选题与课程内容联系较为紧密，能够围绕课程要求展开分析。

## 内容亮点

- 内容上，本文能够围绕……展开讨论，并结合……进行分析，体现出一定的思考。
- 文章在……方面做了较为充分的梳理，能够看出作者有一定的材料整合能力。
- 文中对……的分析较有针对性，能够将课程知识与实际问题联系起来。

## 不足表达

- 但在……方面仍有进一步完善的空间。
- 不过，文章在……方面还可以继续加强。
- 其中，……部分的论证仍偏概括，细节支撑还不够充分。

## 结尾

- 整体来看，学生对课程知识有一定掌握，论文完成度基本达到课程要求。
- 整体来看，论文结构基本完整，但在深度和规范性方面仍有提升空间。
- 整体来看，论文完成质量较好，能够较好体现课程学习成果。

## 句式提醒

- 每篇至少补一句和论文内容相关的话
- 高分先肯定亮点，再点出轻微不足
- 中等分数先概括完成情况，再说主要问题
- 不要重复同一个词太多次
