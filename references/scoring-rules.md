# 通用评分规则

## 一、先确定评分合同

开始评分前，从最新版表格和教师说明中明确：

- 评分项名称、顺序和满分；
- 明示扣分规则；
- 论文总分公式；
- 是否需要课程总评及其数据形态；
- 是否有分数区间、分布、排序或同分限制；
- 用户当前只要结果，还是要求写回文件。

如信息能够从文件中确定，不重复询问。只有缺失信息会实质改变结果且无法合理判断时才向用户确认。

## 二、证据记录

每篇论文至少提取以下证据后再打分：

| 证据 | 要回答的问题 |
|---|---|
| 研究对象 | 论文具体研究谁或什么现象 |
| 核心问题 | 是否明确、具体、贯穿全文 |
| 理论框架 | 使用了哪些课程理论，是否真正参与分析 |
| 材料与数据 | 来源是否可识别，能否支撑判断 |
| 结构 | 摘要、关键词、章节、结论、参考文献是否完整 |
| 亮点 | 哪一处内容体现工作量、思考或区别性 |
| 不足 | 哪一处问题对应实际扣分 |

不得先看目标分数，再倒推不存在的论文证据。

## 三、分项评分

- 优先按评分表原有分项逐项给分，不擅自改名或合并。
- 扣分应落在最直接对应的分项，避免同一缺陷被重复处罚。
- 例如“没有理论框架”主要扣理论运用；只有它进一步导致结构或论证明显失衡时，才在其他项目追加有依据的扣分。
- 工作量和篇幅不等于质量，但可作为材料充分度、完成度和用心程度的辅助证据。
- 图表数量不等于分析质量；应检查是否清晰、标注来源并在正文中得到解释。
- 参考文献数量不等于资料质量；应检查来源可靠性、正文引用和格式一致性。

## 四、常见扣分线索

| 问题 | 主要影响项目 |
|---|---|
| 题目过大、对象不清 | 选题或研究问题 |
| 只有背景介绍，没有明确问题 | 选题、问题意识 |
| 案例事实简单堆积 | 案例描述、材料分析 |
| 理论只在标题出现，正文没有应用 | 知识或理论运用 |
| 建议与前文问题无对应关系 | 分析、创新或策略质量 |
| 缺摘要、关键词、参考文献 | 编辑规范 |
| 图表模糊、无来源、正文未解释 | 撰写、资料或编辑 |
| 结构跳跃、段落重复、表达不顺 | 论文撰写 |
| 结论只复述前文 | 创新、独立思考 |
| 明显大面积粘贴且未整理 | 多项严重扣分并说明 |

具体扣分值以当前表格和论文类型标准为准。

## 五、批量校准

完成所有论文的初评后再横向比较：

1. 比较研究问题、材料、理论、分析、创新和规范性。
2. 检查高分论文是否确有可辨识优势。
3. 检查低分论文是否确有具体缺陷，而非仅为制造分布。
4. 按教师当次要求处理区间、同分和排序。
5. 所有调整回写到具体分项，并同步更新理由和评语。

近似正态分布是课程层面的校准要求，不是单篇论文的评分证据。样本很小时只需做到高低少、中间多，不进行形式化正态检验。

## 六、总评计算

### 百分制加权

当出勤、展示、论文均为百分制：

`课程总评 = 出勤 × 0.20 + 展示 × 0.30 + 论文 × 0.50`

### 已折算分项

当出勤已经是20分制、展示已经是30分制：

`课程总评 = 出勤分项 + 展示分项 + 论文 × 0.50`

如表格已有公式，以表格公式和教师说明为准。不要将已经折算的分项再次乘权重。

## 七、异常情况

- 无法打开论文：记录文件和错误，不凭题目评分。
- 姓名或学号冲突：暂停该生写回，先核对映射。
- 表格总分与小分不一致：保留原值并报告，未经教师确认不自行决定谁正确。
- 论文疑似AI生成：只评价可观察到的内容、结构、引用和格式问题，不仅凭语言风格下结论。
- 缺少部分出勤或展示分：可以完成论文评分，但课程总评标记为待补。
