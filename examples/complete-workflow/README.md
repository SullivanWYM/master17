# 完整匿名工作流

本目录演示从论文分项到课程总评和评语校验的数据衔接。所有身份、论文和成绩均为虚构。

## 场景

- 作业类型：案例分析
- 论文评分项：选题5、案例描述25、知识运用25、论文撰写20、创新10、编辑15
- 总评数据形态：出勤已经折算为20分制，展示已经折算为30分制
- 总评公式：`出勤分项 + 展示分项 + 论文总分 × 0.50`
- 本例不启用正态分布和同分限制，只检查总分区间及一致性

## 操作顺序

1. 根据论文文件建立匿名学生、题目和文件映射。
2. 逐篇记录研究对象、核心问题、理论、材料、亮点和不足。
3. 按案例分析评分表给出六项小分及理由。
4. 使用 `SUM` 或等价逻辑计算论文总分。
5. 将论文总分与出勤、展示分项合成课程总评。
6. 依据最终分数和论文内容写评语。
7. 将结构化结果保存为 `sample-grades.json` 并运行校验脚本。
8. 校验通过后，才写入Excel或Word副本。

## 运行校验

```powershell
python scripts/validate_scores.py examples/complete-workflow/sample-grades.json
```

预期输出：

```text
PASS: 3 record(s) validated.
```

`sample-grades.json` 不是要求教师以后必须使用JSON，而是为AI和脚本提供一个清晰、可测试的中间数据格式。实际任务可以从Excel读取后转换成同等结构。
