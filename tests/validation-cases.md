# 验证样例

## Case 1

- 输入：个人论文，结构完整，有理论，有参考文献
- 期望：给出分项小分，课程总评正常，评语包含 1 个具体亮点

## Case 2

- 输入：小组论文，存在展示分排名
- 期望：展示分与名次一致，总评按比例计算，评语使用“小组”措辞

## Case 3

- 输入：格式不规范、摘要缺失、理论薄弱
- 期望：编辑项和理论项扣分，评语明确指出主要不足

## Case 4

- 输入：老师修改了评分比例或话术
- 期望：先更新 `references/configuration.md` 或 `references/comment-style.md`，再执行后续任务
